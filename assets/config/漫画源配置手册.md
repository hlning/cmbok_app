## 一、总览

### 1.1 文件结构

`sources.json` 顶层结构：

```json
{
  "version": 1,
  "sources": [
    { "type": "config", "config": { ... } },
    { "type": "api", "engine": "zaimanhua", "config": { ... } }
  ]
}
```

- `version`：配置版本号（整数，当前为 `1`，一般不用改）。
- `sources`：源定义数组，**每个元素是一个 source 对象**。顺序影响 UI 中的展示顺序。

### 1.2 三种源类型 —— 选哪一种？

| 类型 | `type` / `engine` | 工作方式 | 你能新增全新网站吗？ |
|---|---|---|---|
| **网页源** | `type: "config"` | 用 CSS 选择器抓 HTML 页面 | ✅ **可以**，这是你新增源的主要方式 |
| **再漫画源** | `type:"api"` + `engine:"zaimanhua"` | 调 JSON 接口（zaimanhua 协议） | ❌ 只能换域名复用同协议姊妹站 |
| **漫画人源** | `type:"api"` + `engine:"manhuaren"` | HTML + JSON 混合（dm5 系） | ❌ 只能换域名复用 dm5 同源站 |

> **重要**：API 源（zaimanhua / manhuaren）是针对**特定协议写死的代码引擎**，配置只能改「域名 / 路径 / 字段名映射」。如果你想接入一个**全新的、协议不同的网站**，请用 `type: "config"`（网页源），它完全由配置驱动、无需写代码。

### 1.3 源 id 派生规则（重要）

源的 `id` 用于持久化「当前选中源」，由类型自动派生，**不要手动写 id 字段**：

| 类型 | id 派生规则 | 举例 |
|---|---|---|
| `config` | `config:` + `config.name` | `name:"MYCOMIC"` → id = `config:MYCOMIC` |
| `api` | 直接取 `config.id`（缺省回退到 `engine` 名） | `config.id:"zaimanhua"` → id = `zaimanhua` |

⚠️ **`config` 源的 `name` 必须全局唯一**，否则两个源会撞 id。

### 1.4 两种源的最小骨架

```jsonc
// 网页源（最常见）
{
  "type": "config",
  "config": {
    "name": "我的漫画站",
    "url": "https://example.com/",
    "comic_name_dom": "...",
    "chapter_name_dom": "...",
    "chapter_link_dom": "...",
    "img_dom": "..."
  }
}

// API 源（仅复用现有引擎）
{
  "type": "api",
  "engine": "zaimanhua",
  "config": { "id": "zaimanhua", "base": "https://manhua.zaimanhua.com/" }
}
```

## 二、快速上手：新增一个网页源

假设你要接入 `https://www.example.com/`，步骤如下：

1. **填基本信息**：`name`（唯一）、`url`（带结尾 `/`）、可选 `icon`（logo 图片 URL）。
2. **打开一个漫画详情页**，用浏览器 F12 找到：标题、作者、简介、封面的 CSS 选择器 → 填 `comic_*_dom`。
3. **找到章节列表**的章节名 / 链接选择器 → 填 `chapter_name_dom` / `chapter_link_dom`。
4. **打开一个章节阅读页**，找到图片的 CSS 选择器 → 填 `img_dom`。
5. **决定章节排序**：站点章节列表「最新在前」填 `"chapter_order": 0`（倒序），「第一话在前」填 `1`（正序）。
6. **决定取图模式** `use_frame`：普通站点填 `0`（直连）；Cloudflare 防护 / 图片需 JS 渲染的站填 `1`（WebView 注入）。

最小可用配置：

```jsonc
{
  "type": "config",
  "config": {
    "name": "示例漫画",
    "url": "https://www.example.com/",
    "comic_name_dom": "h1.title",
    "comic_cover_dom": ".cover img",
    "chapter_name_dom": ".chapter-list a",
    "chapter_link_dom": ".chapter-list a",
    "img_dom": ".read-content img",
    "chapter_order": 0,
    "use_frame": 0
  }
}
```

填完搜索、分类字段后即可获得完整体验。下面是**全部字段**的逐一说明。

## 三、顶层字段（每个 source 对象）

每个 `sources[]` 数组元素支持以下字段：

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `type` | string | `"config"` | 源类型：`"config"` 或 `"api"` |
| `engine` | string | — | `type:"api"` 时必填：`"zaimanhua"` 或 `"manhuaren"` |
| `needsMagic` | bool | `false` | 是否需要代理 / VPN 才能访问（源元数据，UI 会提示，不影响抓取逻辑） |
| `config` | object | `{}` | 配置体，内容随 `type`/`engine` 而变 |

`needsMagic` 示例（被墙站点）：

```jsonc
{ "type": "config", "needsMagic": true, "config": { "name": "包子漫画", "url": "https://cn.baozimh.com/", ... } }
```

## 四、网页源字段详解（type=config）

`type:"config"` 时，`config` 体解析为 `SiteConfig`。**所有字段都有默认值**，缺省仍可工作，可渐进配置。字段名一律 `snake_case`。

### 4.1 基本信息

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `name` | string | **必填** | 源名称，全局唯一（决定 id = `config:<name>`） |
| `url` | string | **必填** | 站点首页，**建议带结尾 `/`**（作为相对 URL 的拼接基准与默认 Referer） |
| `icon` | string | 空 | 源 logo 图片 URL（可选） |

```jsonc
{ "name": "来漫画", "icon": "https://www.comemh8.com/.../logo.png", "url": "https://www.comemh8.com/" }
```

### 4.2 详情页 DOM 选择器

漫画详情页中各信息的 CSS 选择器：

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `comic_name_dom` | string | `""` | 漫画标题元素 |
| `comic_cover_dom` | string | `""` | 封面 `<img>` 元素（取其图片地址） |
| `comic_author_dom` | string | `""` | 作者元素 |
| `author_label` | string | 空 | 作者区前缀文案，如 `"原著作者"`；设置后取「去掉该 label 后的剩余文本」 |
| `comic_desc_dom` | string | `""` | 简介元素（若是 `meta[property=...]` 取 `content`，否则取文本） |

```jsonc
"comic_name_dom": ".intro_l .title h1",
"comic_cover_dom": ".info_cover .cover img",
"comic_author_dom": ".info p.w260",
"author_label": "原著作者",
"comic_desc_dom": ".introduction"
```

### 4.3 章节列表 DOM 选择器（详情页）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `chapter_name_dom` | string | `""` | 章节名元素 |
| `chapter_link_dom` | string | `""` | 章节链接元素（取 `href`） |
| `chapter_url_pattern` | string | `""` | 章节链接 `href` 必须包含的片段；空 = 不过滤。用于排除推荐、相关漫画等非章节链接 |
| `chapter_order` | int | `1` | `0`=倒序（最新在前，**多数站点用这个**）/ `1`=正序 |
| `chapter_sort_by_order` | bool | `false` | `true`=按 DOM 顺序排，跳过智能排序（按更新时间排的站点用） |

> `chapter_name_dom` 与 `chapter_link_dom` 常填同一选择器（如 `.chapter-list a`），此时 a 标签既是链接、文本又是章节名。

`chapter_url_pattern` 示例（MYCOMIC 用它排除非章节链接）：

```jsonc
"chapter_url_pattern": "/cn/chapters/"
```

### 4.4 章节分页（PC 网页分页站点）

部分站点详情页的章节列表分多页（如 PC 版「第 1-50 话 / 51-100 话」）。仅当站点确实分页时才填，否则全部留空：

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `chapter_paged_url` | string | `""` | 分页 URL 模板，`{base}`=基础URL、`{page}`=页码，如 `"{base}&page={page}"` |
| `chapter_paged_base_dom` | string | `""` | 基础 URL 选择器（如 `meta[property="og:url"]` 取 content）；空=用详情页 URL |
| `chapter_page_count_dom` | string | `""` | 总页数容器选择器（取其中最大数字）；空=不分页 |

### 4.5 取图配置（核心）

打开一个章节阅读页，图片如何被取到：

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `img_dom` | string | `""` | 章节页所有 `<img>` 的选择器 |
| `img_attr` | string | `""` | 图片地址属性名；空=`src`。懒加载站点常用 `data-src` / `data-original` |
| `use_frame` | int | `1` | `0`=直连（Dio 抓 HTML 解析）/ `1`=WebView iframe 注入（JS 渲染 / 反爬站点） |
| `img_script` | string | `""` | 取图 JS 片段（`use_frame:1` 时在 WebView 内执行，`return` 图片 URL 数组）。优先级高于 `img_dom` |
| `img_load_mode` | int | `1` | 阅读器滚动模式：`1`=滚动 / `2`=滚到底 / `3`=下一页翻页 |
| `next_page_selector` | string | `""` | 「下一页」按钮选择器（`img_load_mode:3` 时用） |
| `page_label_selector` | string | `""` | 当前页码标签选择器（`img_load_mode:3` 时用） |
| `img_referer` | string | `""` | 图片请求 Referer：空=用 `url` / `"none"`=不发 / 其他字符串=自定义值 |
| `cross_origin` | int | `0` | `0`=同源 / `1`=跨源（图片域名与站点不同时开启） |
| `url_rewrites` | object | — | 图片 URL 子串替换 map（封面/章节图主机被防盗链或地理拦截时换可达主机） |
| `restore_algorithm` | string | `""` | 图片还原算法名（特殊站点，如「腐漫」），一般不用 |

**`use_frame` 怎么选**：

- 站点图片地址直接在 HTML 里（`src` 或 `data-*`）→ `use_frame:0`（更快）。
- 站点图片靠 JS 加载、或有 Cloudflare 等反爬 → `use_frame:1`（用 WebView 渲染后取图）。

**`img_script` 示例**（来漫画：章节图地址在 JS 变量里，需拼接主机）：

```jsonc
"use_frame": 1,
"img_script": "var h; if (parseInt(mhInfo.chapterId) > 542724) { var hosts = [\"xwdf.tgmhfc.uk\",\"mhreswhm.tgmhfc.uk\"]; h = \"https://\" + hosts[Math.floor(Math.random()*hosts.length)]; } else { h = \"https://mhpic6.tgmhfc.uk\"; } return mhInfo.images.map(function(e){ return h + mhInfo.path + e; });"
```

**`img_script` 示例**（MANGA：图片在全局变量 `newImgs` 里）：

```jsonc
"img_script": "return (typeof newImgs!==\"undefined\"&&newImgs)?newImgs:[];"
```

**`url_rewrites` 示例**（包子漫画：图片主机被拦截，换可达 CDN）：

```jsonc
"url_rewrites": { "static-tw.baozimh.com": "s1.bzcdn.net" }
```

### 4.6 搜索配置

搜索功能为可选项，不配则该源不支持搜索：

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `search_url` | string | 空 | 搜索 URL 模板，`{q}` = 关键词占位（相对 `url`） |
| `search_result_dom` | string | 空 | 搜索结果列表项选择器 |
| `search_title_dom` | string | 空 | 结果项标题选择器（缺省则用 `search_result_dom` 文本） |
| `search_cover_dom` | string | 空 | 结果项封面 `<img>` 选择器 |
| `search_manga_url_dom` | string | 空 | 结果项→详情页链接选择器（取 `href`） |
| `search_encoding` | string | `utf-8` | 搜索关键词编码；Empire CMS（帝国cms）站用 `gb2312` |
| `use_webview_fetch` | bool | `false` | `true`=搜索/分类/详情/章节全走 WebView 抓 HTML（Cloudflare 防护站，Dio 被拦时用） |

```jsonc
"search_url": "/search?q={q}",
"search_result_dom": ".comics-card",
"search_manga_url_dom": "a",
"search_cover_dom": "amp-img"
```

gb2312 编码站点（来漫画，帝国 CMS）：

```jsonc
"search_url": "/e/search/?key={q}",
"search_encoding": "gb2312",
"page_encoding": "gb2312"
```

> `page_encoding`（见 4.8）控制页面响应解码，与 `search_encoding`（关键词编码）独立。帝国 CMS 站两者通常都设 `gb2312`。

### 4.7 分类浏览配置

分类 / 浏览页（首页按题材筛选）为可选项：

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `categories` | array | — | 预定义分类列表，每项 `{value, name, isAll?}`（`value`=URL slug，`name`=显示名） |
| `category_url` | string | 空 | 分类**第 1 页** URL 模板，`{slug}` 占位（相对 `url`） |
| `category_page_url` | string | 空 | 分类**第 2 页起** URL 模板，`{slug}`+`{page}`（page 从 1 起） |
| `category_list_dom` | string | 空 | 分类列表项选择器 |
| `category_cover_dom` | string | 空 | 分类项封面 `<img>` 选择器 |
| `category_title_dom` | string | 空 | 分类项标题选择器 |
| `category_url_dom` | string | 空 | 分类项→详情页链接选择器（取 `href`） |
| `category_next_page_dom` | string | 空 | 「下一页」链接选择器（存在即判定还有下一页） |
| `category_page_size` | int | `0` | 计数式分页每页条数；`>0` 时满页即判定有下一页；链接式分页留 `0` |
| `category_page_start` | int | `1` | 分页页码起始偏移；URL 形如 `page{page}.html` 且 `page1`=第2页时填 `0` |

**`categories` 示例**：

```jsonc
"categories": [
  { "value": "rexue", "name": "热血" },
  { "value": "aiqing", "name": "恋爱", "isAll": false }
]
```

**计数式分页**（包子漫画，每页固定 36 条，满 36 即有下一页）：

```jsonc
"category_url": "/classify?type={slug}&region=all&state=all&filter=%2a",
"category_page_url": "/classify?type={slug}&region=all&state=all&filter=%2a&page={page}",
"category_list_dom": ".comics-card",
"category_cover_dom": "amp-img",
"category_url_dom": "a",
"category_page_size": 36
```

**链接式分页**（来漫画，靠下一页按钮判断）：

```jsonc
"category_url": "/kanmanhua/{slug}/",
"category_page_url": "/kanmanhua/{slug}/{page}.html",
"category_list_dom": "div.dmList li",
"category_cover_dom": ".cover .pic img",
"category_title_dom": "dl dt a",
"category_url_dom": "dl dt a",
"category_next_page_dom": "a#k_1"
```

**`category_page_start` 用法**（来漫画2：URL 是 `/manga{slug}/page1.html` 表示第 2 页，故 page 码从 0 偏移）：

```jsonc
"category_url": "/manga{slug}",
"category_page_url": "/manga{slug}/page{page}.html",
"category_page_size": 24,
"category_page_start": 0
```

### 4.8 其他 / 高级

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `page_encoding` | string | `utf-8` | 页面响应解码；帝国 CMS（来漫画等）用 `gb2312` |

> 字段名速查：所有 snake_case，包含 `_dom` 后缀的都是 CSS 选择器；`_url` 是模板（含 `{q}`/`{slug}`/`{page}` 占位）；`_size`/`_mode`/`_order` 是数值枚举。

## 五、API 源总则（type=api）

`type:"api"` 的源由代码引擎驱动，`config` 体只填**该引擎的可变配置**（域名 / 路径 / 字段映射）。所有字段都有与线上站点一致的默认值，**不写任何字段也能跑**。

目前支持两个引擎：

| engine | 适用站点族 | 配置类 |
|---|---|---|
| `zaimanhua` | 再漫画（zaimanhua）系 SPA | `ZaimanhuaConfig` |
| `manhuaren` | 漫画人 / 动漫屋 dm5 系 | `ManhuarenConfig` |

> ⚠️ 复用引擎接入姊妹站时，**通常只需改 `base`（域名）和 `ua`**，字段映射只在姊妹站字段名不同时才覆盖。

通用必填字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 协议标识，全局唯一（成为源 id）。缺省会回退到 engine 名 |
| `base` | string | 站点首页 / API base，建议带结尾 `/` |
| `ua` | string | 请求 User-Agent（缺省用内置 Chrome UA） |

## 六、再漫画引擎字段详解（engine=zaimanhua)

`zaimanhua` 引擎走 JSON 接口（响应包络 `{errno, data, errmsg}`），覆盖搜索 / 分类 / 详情 / 取图四套接口。

### 6.1 顶层

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `id` | string | `"zaimanhua"` | 源标识 |
| `base` | string | `https://manhua.zaimanhua.com/` | API base |
| `ua` | string | 内置 Chrome UA | 请求头 |
| `hotUnits` | object | `{"万":10000,"千":1000}` | 热度字符串单位映射 |
| `delistedStatus` | string | `"已下架"` | 下架状态文案（匹配到则判定下架） |
| `delistedTextPrefix` | string | `"⚠️ 该漫画章节已被源站下架删除，暂无法阅读"` | 下架详情提示前缀 |

### 6.2 `envelope` —— 响应包络

```jsonc
"envelope": {
  "codeField": "errno",      // 状态码字段名
  "dataField": "data",       // 数据体字段名
  "msgField": "errmsg",      // 错误消息字段名
  "successCode": 0           // 成功时的状态码值
}
```

### 6.3 `search` —— 搜索接口

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `path` | string | `app/v1/search/index` | 接口路径 |
| `queryKey` | string | `keyword` | 关键词参数名 |
| `pageKey` | string | `page` | 页码参数名 |
| `sizeKey` | string | `size` | 每页条数参数名 |
| `size` | int | `20` | 每页条数（同时用于是否有下一页判断） |
| `listField` | string | `list` | 结果列表字段名 |
| `idField` | string | `id` | 单条结果 id 字段名 |
| `fields` | object | 见下 | 结果项字段映射 |

`fields` 默认值（key 固定，value 是源站实际字段名）：

```jsonc
"fields": { "title": "title", "cover": "cover", "authors": "authors", "status": "status", "hot": "hot_hits" }
```

## 七、漫画人引擎字段详解（engine=manhuaren)

`manhuaren` 引擎属动漫屋 dm5 系：搜索=裸 JSON、分类页1=HTML / 页2+=POST JSON、详情+章节=HTML SSR、取图=`eval(packer)` 解包。

> 默认值已对齐 `manhuaren.com` 线上，**接入 dm5 同源姊妹站（如动漫屋 dm5.com）通常只改 `base`**。

### 7.1 顶层

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `id` | string | `"manhuaren"` | 源标识 |
| `base` | string | `https://www.manhuaren.com/` | 站点首页 |
| `ua` | string | 内置 Chrome UA | 请求头 |
| `categories` | array | 内置 25 个热门分类 | 预定义分类 `{value, name}`（value=路径 slug，不走远端） |
| `categoryPageSize` | int | `10` | 分类每页条数（满页即有下一页） |

`categories` 示例：

```jsonc
"categories": [
  { "value": "rexue", "name": "热血" },
  { "value": "aiqing", "name": "恋爱" }
]
```

### 7.2 `search` —— 搜索接口（search.ashx 裸 JSON 数组）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `path` | string | `search.ashx` | 接口路径 |
| `queryKey` | string | `t` | 关键词参数名 |
| `languageKey` / `languageValue` | string | `language` / `1` | 语言参数（manhuaren 固定 1=中文） |
| `removeHtmlKey` / `removeHtmlValue` | string | `isremovehtml` / `1` | 是否去 HTML |
| `fields` | object | 见下 | 结果项字段映射 |

`fields` 默认：`{"id":"ID","title":"Title","url":"Url","lastPartUrl":"LastPartUrl","lastPartName":"LastPartName"}`

> search.ashx 不返回封面，`cover` 留空（详情页补全）。

### 7.3 `category` —— 分类页（页1 HTML / 页2+ POST JSON）

| 字段 | 类型 | 默认 | 说明 |

| `tagIdKey` | string | `tagid` | 分类 tagid 参数名 |
| `fixedParams` | object | 见下 | 其它固定参数 |
| `listField` | string | `UpdateComicItems` | JSON 结果列表字段 |
| `itemFields` | object | 见下 | JSON 结果项字段映射 |
| `htmlListItemDom` | string | `ul.manga-list-2 > li` | 第 1 页 HTML 列表项选择器 |

## 九、配置覆盖与分发

应用启动时按以下优先级合并源配置（高优先级覆盖低优先级同 id 的源）：

1. **应用私有文档目录的 `sources.json`**（用户 / 远端更新覆盖层）
2. **`assets/config/sources.json`**（出厂默认，随 APK 打包）

- 改 `assets/config/sources.json` 需重新打包；改文档目录的 `sources.json` 可热更新（应用内「源仓库」页面或远端下发会写入这里）。
- 同名（同 id）的源会被覆盖层版本替换；新增的源会追加。
- `version` 字段当前仅作标识，升级时一般保持 `1`。

> 日常自配新源：直接编辑 `assets/config/sources.json` 并重新运行 app 即可生效。

## 十、排错速查表

| 现象 | 排查方向 |
|---|---|
| 源不出现在列表 | `name` 重复（id 冲突）；JSON 语法错误（逗号/括号）→ app 回退默认 |
| 详情页标题/封面为空 | `comic_*_dom` 选择器写错；站点改版 → F12 重新取选择器 |
| 章节列表空 | `chapter_name_dom` / `chapter_link_dom` 错；含非章节链接干扰 → 配 `chapter_url_pattern` 过滤 |
| 章节顺序颠倒 | 改 `chapter_order`：`0`=倒序 / `1`=正序 |
| 图片不显示（空白） | 懒加载站没配 `img_attr`（如 `data-src`）；或需 `use_frame:1` 走 WebView |
| 图片 403 / 防盗链 | 配 `img_referer`；或用 `url_rewrites` 换可达主机；跨域图片开 `cross_origin:1` |
| 搜索结果乱码 | 帝国 CMS 站设 `search_encoding` 和 `page_encoding` 为 `gb2312` |
| Cloudflare 拦截（Dio 取不到内容） | 开 `use_webview_fetch: true`；取图改 `use_frame:1` |
| 分类翻页错乱 | 计数式站确认 `category_page_size` 正确；`page1` 表第 2 页的站设 `category_page_start:0` |
| 需翻墙才能访问 | 顶层加 `"needsMagic": true`（仅 UI 提示） |
